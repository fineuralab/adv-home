# ADV Home v0.1

The English interface uses Roboto Regular for menu labels, filenames and
readouts, and Roboto Medium for page headings and app titles. The original
Google Fonts asset and its SIL Open Font License 1.1 are included in the source
and notice packages.

The ESP-IDF build, host tests and image checks passed. Hardware testing for
v0.1 is pending.

Owners of ADV Home N1, N1.1 or N1.2 can write `ADV-Home-v0.1-update_0x10000.bin`
at `0x10000` with **Erase all** disabled to keep their apps and Home settings.
For a first installation on Cardputer ADV, write `ADV-Home-v0.1_0x0.bin`
at `0x0`. The complete image initializes the Flash application slots and
Home configuration.

See the [installation guide](../INSTALL.md) and [third-party notices](../../NOTICE.md).
